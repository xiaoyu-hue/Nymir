## ✦ sonder520: My First Project

I started by following a blogger's tutorial to build v1. From there, it was all self-exploration.

I've always loved ink-wash style and liquid glass style, so I kept wondering: can these two be combined? I tried it, and it actually worked. Then I felt the background was missing, so I used my favorite wallpaper. Later I wanted more personalization, so I added a custom wallpaper feature with adjustable transparency to match the overall aesthetic.

<div align="center">

> **sonder** · a passerby &nbsp;|&nbsp; **520** · a gift to myself

</div>

The project is called sonder520 — "sonder" means a passerby, "520" is a gift to myself. It's my first official AI Agent project.

### From Local to Online

The tutorial version could only be viewed locally, and I wanted others to see it too. So I asked AI how to deploy it, and it recommended several static hosting platforms.

I first deployed on Netlify — my first time completing a deployment on my own. Later, when Netlify's build quota ran out, I configured GitHub Pages and Cloudflare Pages. The ongoing deployment sync was handed off to AI Agent.

### From Workspace to Personal OS

Now sonder520 has nearly all the modules I need, but each module's content can be deepened further, and cross-module collaboration has a lot of room for improvement. I don't think it fits the label of "personal workspace" anymore — it's more like a personal OS.

From v1.0 step by step to v5.2, and now v6.0, it's been a genuinely rewarding journey. Once I get a new device, I'll continue iterating.

## ✦ Nymir: Another Idea Realized

Nymir came from another question: is there a place for confiding and chatting that prioritizes security, privacy, and anonymity, without being logged by centralized servers?

Services like TikTok, QQ, and WeChat are centralized — chat logs are typically stored on their servers. Nymir has no central server and doesn't record your data — everything stays local. Anonymity is achieved through end-to-end encryption, randomly generated names, and no registration required. It's essentially a secret tree hollow — a place where you can confide with peace of mind.

Nymir's visual system combines liquid glass style with a starry sky theme.

Of course, this isn't absolutely secure. While it uses cutting-edge technologies, I'm simply standing on the shoulders of giants to realize my own ideas.
