# ADR-002：采用 AGPL-3.0 开源协议

- 状态：Accepted
- 日期：2026-09-08（v1.0 开发期）
- 相关：`LICENSE`、`package.json`（`license: AGPL-3.0`）、[README.md](../README.md)「开源协议」

## 背景

Nymir 的核心价值是隐私与本地优先。选择协议时需要同时考虑：允许社区自由使用与改进；防止他人以闭源方式利用本项目的安全设计并获利而不回馈。

## 决策

采用 **AGPL-3.0**（Affero GPL v3）。与 GPL 相比，AGPL 额外约束"通过网络提供服务"的场景——即使不分发软件副本，仅以网络服务形式运行修改版，也必须向用户公开其源代码。

## 后果

- **收益**：任何基于 Nymir 做修改并提供服务/分发的人，都需以 AGPL-3.0 公开其修改；社区改进可回流入项目。
- **代价**：与宽松协议（MIT/Apache）生态互操作性受限——引用本项目代码的闭源项目不可接受；对只想内嵌一小段代码的潜在贡献者构成门槛。

## 替代方案

- MIT/Apache-2.0：生态友好，但允许闭源商用分叉，隐私项目的核心改进可能被拿走而不回馈。
- GPL-3.0：可接受，但无法约束"仅作网络服务"的 SaaS 场景，对消息类产品留有后门。
